# Samarth Fish – Bhigwan Billing System

## Files
- `index.html` – application layout
- `style.css` – application design
- `app.js` – billing, fish management, reports, login and backup logic
- `logo.png` – Samarth Fish logo used on login and printed receipts

## Fish management
Fish Management now contains only a fish-name field and Add Fish button. The fish list displays fish names and delete actions only. No catalog rate is stored.

## Billing
Select a fish, enter weight and rate in the calculator, then add it to the current bill. Weight and rate reset for every new fish selection. The owner enters the rate on each transaction.

## Run
Keep all four files in the same folder and open `index.html` in a modern browser. Existing browser localStorage data is retained; export a backup before clearing browser data.

Default login (unless previously changed): `admin` / `admin123`.
